# My Life OS

**가입도, 월 결제도 없는 개인 Life OS.** 링크를 열면 그게 앱입니다.

👉 **https://hyein-lgtm.github.io/my-life-os/**

할 일 · 프로젝트 · 업무 · 독서 · 운동 · 브랜드 · 부동산 — 일곱 가지 기록을 한 화면에서 관리하고, 안 쓰는 건 꺼두면 됩니다. 기록은 내 기기에 저장되고, 홈 화면에 추가하면 앱처럼 사용할 수 있습니다.

---

## 시작하기

1. 위 주소를 **휴대폰에서** 엽니다
2. 이름을 적고 시작 구성을 고릅니다 (30초)
3. **홈 화면에 추가**합니다
4. 첫 할 일을 하나 적습니다

여기까지 1분이면 끝납니다. 이후에는 홈 화면 아이콘을 눌러 앱처럼 열면 됩니다.

### 홈 화면에 추가하는 법

| 어디서 열었나 | 방법 |
|---|---|
| **아이폰 · Safari** | 화면 하단 가운데 **공유 버튼** → 목록에서 **「홈 화면에 추가」** → 오른쪽 위 **「추가」** |
| **아이폰 · 인스타그램/카카오톡 등 앱 안** | 앱 안의 브라우저에서는 추가가 안 됩니다. 오른쪽 위(또는 아래)의 **「…」** → **「외부 브라우저에서 열기」** 또는 **「Safari에서 열기」** → 그다음 위와 같이 |
| **안드로이드 · Chrome** | 설정이 끝나면 뜨는 **「앱으로 설치하기」** 버튼. 안 보이면 오른쪽 위 **「⋮」** → **「홈 화면에 추가」** 또는 **「앱 설치」** |

앱 안에서도 **설정 → 📲 홈 화면에 추가**에서 같은 안내를 다시 볼 수 있습니다. 이미 추가했다면 그 자리에 **「홈 화면에 설치됨」**이라고 표시됩니다.

## 내 화면으로 바꾸기

처음 열면 안내 화면이 네 단계로 지나갑니다.

- **1단계 — 안내** — 가입이 필요 없다는 것, 기록이 이 기기에만 저장된다는 것, 백업을 권한다는 것
- **2단계 — 이름** — 화면 곳곳에서 부를 이름 (비워도 됩니다)
- **3단계 — 시작 방법** — **「30초 체험하기」**(예시 데이터) / **「빈 노트로 시작하기」**
- **4단계 — 시작 구성** — **가볍게**(투두·프로젝트·운동) / **균형 있게**(투두·프로젝트·독서·운동) / **전체 둘러보기**

끝나면 **「설정이 완료됐어요!」** 안내가 떠서 홈 화면 추가를 도와주고, 그다음 **「가볍게 시작해볼까요?」** 카드가 한 번 떠서 첫 할 일을 바로 적게 해줍니다. 둘 다 닫으면 다시 뜨지 않습니다.

설정 화면은 일곱 칸입니다: 💡 이런 것도 있어요, 💾 파일 백업, 📲 홈 화면에 추가, 🎛 사용할 탭 선택, 🌙 다크모드, 🧑 이름 변경, ⚙ 고급 동기화. 맨 아래에 작은 글씨로 초기화 링크가 있습니다.

**💡 이런 것도 있어요**는 눈에 잘 안 띄는 기능을 한 화면에 모아둔 도움말입니다. 메모 형광펜, 빠른 메모 → 📥 인박스, ♺ 반복 루틴, 계속 밀린 할 일을 프로젝트로 옮기기, 탭 이름 바꾸기·순서 바꾸기, 백업 알림 같은 것들을 설명합니다.

**🎛 사용할 탭 선택**에서는 탭마다 세 가지를 할 수 있습니다.

- **보임 / 숨김** — 탭 이름을 눌러 바꿉니다. 숨겨도 안에 있던 기록은 그대로 보관됩니다.
- **✏️ 이름** — 탭 이름을 원하는 말로 바꿉니다 (예: "업무 관련" → "회사일"). 비우고 확인하면 원래 이름으로 돌아갑니다.
- **🗑 삭제** — 탭과 그 안의 기록까지 지웁니다. **저장**을 누르기 전이라면 되돌릴 수 있고, 지운 뒤에도 같은 화면 아래쪽 "지워둔 탭"에서 빈 상태로 다시 만들 수 있습니다.

같은 화면의 **순서 바꾸기** 버튼으로 탭이 보이는 순서도 정할 수 있습니다.

## 내 기록은 어디에 있나

**작성한 기록은 현재 기기의 브라우저에 저장됩니다.** 별도 서버로 전송하거나 저장하지 않아요. 그래서 브라우저 데이터 삭제 또는 기기 변경 시 기록이 사라질 수 있으므로, 중요한 기록은 주기적으로 백업해주세요.

- 다른 기기에서는 안 보입니다
- 브라우저 데이터를 지우면 같이 사라집니다
- 시크릿 모드에서 쓰면 창을 닫는 순간 없어집니다
- **홈 화면에 추가한 앱을 삭제하면 그 기기에 저장된 기록도 같이 지워집니다.** 지우기 전에 반드시 내보내기를 먼저 하세요

백업은 **설정 → 💾 파일 백업 → 「파일로 내보내기」**입니다. JSON 파일 하나에 모든 기록이 들어 있고, 새 기기에서는 같은 자리에서 그 파일을 고르면 그대로 되살아납니다. 마지막 백업 후 14일이 지나면 화면 위에 안내가 한 번 뜹니다.

정확히 하자면, 페이지 자체는 외부에서 두 가지를 내려받습니다. 글꼴(Pretendard, jsDelivr CDN)과 — **설정 → ⚙ 고급 동기화를 직접 열었을 때만** — 구글 로그인 스크립트입니다. 동기화를 켜지 않으면 구글 쪽으로는 아무 요청도 나가지 않습니다. 켠 경우에도 파일은 본인 구글 드라이브의 `mylifeos.json` 하나에만 저장됩니다.

기록이 갑자기 안 보일 때를 대비한 안전장치가 세 겹 들어 있습니다. 저장 이름표만 바뀐 경우라면 앱이 알아서 예전 기록을 찾아 되살립니다. 정말 못 찾으면 **「🔎 기록을 찾지 못했어요」** 화면이 먼저 뜨고, 여기서 하나를 고르기 전까지는 아무것도 덮어쓰지 않습니다. 그래서 예시 데이터가 실제 기록을 밀어내는 일이 생기지 않습니다.
