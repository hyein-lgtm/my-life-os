# My Life OS

**파일 하나로 굴러가는 개인 대시보드.** 서버도, 회원가입도, 월 구독료도 없습니다. `index.html` 하나를 브라우저로 열면 그게 앱입니다.

프로젝트 · 업무 · 데일리 투두 · 독서 · 운동 · 브랜드 · 부동산 — 일곱 가지 기록을 한 화면에서 관리하고, 필요 없는 건 꺼두면 됩니다.

👉 **데모: https://hyein-lgtm.github.io/my-life-os/**
(둘러보기용 예시 데이터가 채워져 있어요. 브라우저에만 저장되니 마음껏 눌러보세요.)

## 5분 만에 내 것으로 만들기

1. 이 저장소 오른쪽 위 초록색 **`Use this template`** → **`Create a new repository`**
2. 저장소 이름을 정하고 **Public**으로 만들기
3. 만들어진 저장소에서 **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`** → Save
4. 1~2분 뒤 `https://<내이름>.github.io/<저장소이름>/` 접속
5. 안내를 읽고 이름을 적은 뒤, 시작 방법을 고르면 끝

자세한 그림 설명은 [DEPLOY.md](DEPLOY.md)에 있습니다.

**GitHub 없이 쓰고 싶다면** — `index.html`을 다운로드해서 더블클릭하면 그대로 동작합니다. 다만 휴대폰에서 쓰려면 어딘가에 올려두는 편이 편해요.

## 커스터마이징

### 방법 A — 화면에서 (코드 몰라도 됨)

처음 열면 안내 화면이 네 단계로 지나갑니다.

- **1단계 — 안내** — 가입이 필요 없다는 것, 기록이 이 브라우저에만 저장된다는 것, 백업을 권한다는 것
- **2단계 — 이름** — 화면 곳곳에서 부를 이름 (비워도 됩니다)
- **3단계 — 시작 방법** — **「30초 체험하기」**(예시 데이터) / **「빈 노트로 시작하기」**
- **4단계 — 시작 구성** — **가볍게**(투두·프로젝트·운동) / **균형 있게**(투두·프로젝트·독서·운동) / **전체 둘러보기**

끝나면 **「가볍게 시작해볼까요?」** 카드가 한 번 떠서 첫 할 일을 바로 적게 해줍니다. 닫으면 다시 뜨지 않습니다.

설정 화면은 일곱 칸입니다: 💡 이런 것도 있어요, 💾 파일 백업, 📲 홈 화면에 추가, 🎛 사용할 탭 선택, 🌙 다크모드, 🧑 이름 변경, ⚙ 고급 동기화. 맨 아래에 작은 글씨로 초기화 링크가 있습니다.

**💡 이런 것도 있어요**는 눈에 잘 안 띄는 기능을 한 화면에 모아둔 도움말입니다. 메모 형광펜, 빠른 메모 → 📥 인박스, ♺ 반복 루틴, 계속 밀린 할 일을 프로젝트로 옮기기, 탭 이름 바꾸기·순서 바꾸기, 백업 알림 같은 것들을 설명합니다. 첫 실행 때 튜토리얼로 강제하지 않고, 궁금하면 열어보게 두었습니다.

**🎛 사용할 탭 선택**에서는 탭마다 세 가지를 할 수 있습니다.

- **보임 / 숨김** — 탭 이름을 눌러 바꿉니다. 숨겨도 안에 있던 기록은 그대로 보관됩니다.
- **✏️ 이름** — 탭 이름을 원하는 말로 바꿉니다 (예: "업무 관련" → "회사일"). 비우고 확인하면 원래 이름으로 돌아갑니다.
- **🗑 삭제** — 탭과 그 안의 기록까지 지웁니다. **저장**을 누르기 전이라면 되돌릴 수 있고, 지운 뒤에도 같은 화면 아래쪽 "지워둔 탭"에서 빈 상태로 다시 만들 수 있습니다.

같은 화면의 **순서 바꾸기** 버튼으로 탭이 보이는 순서도 정할 수 있습니다.

### 방법 B — 파일에서 (배포 전에 미리 정해두고 싶을 때)

`index.html` 맨 위에 설정 블록이 있습니다. 여섯 줄이 전부입니다.

```js
window.CONFIG = {
  appName:  "My Life OS",   // 앱 이름 (탭 제목 · 홈 화면 아이콘 이름)
  owner:    "",             // 나를 부르는 말. 비워두면 첫 실행 때 물어봐요
  tagline:  "",             // 부제. 비워두면 "OO's workspace"
  storeKey: "mylifeos",     // 저장소 이름표. 한 브라우저에서 2개 쓰려면 다르게
  tabs:     null,           // (예약) null = 전부
  sample:   true            // true = 예시 데이터로 시작 / false = 빈 상태로 시작
};
```

**`owner`에 이름을 적어두면 안내 화면은 건너뜁니다.** 개발자가 이미 설정을 마쳤다고 보기 때문이에요. 안내를 보여주고 싶으면 `owner`를 비워두세요.

`storeKey`는 브라우저 저장소의 이름표입니다. 같은 브라우저에서 "업무용"과 "개인용"을 따로 쓰고 싶다면, 파일 두 개를 서로 다른 `storeKey`로 두면 데이터가 섞이지 않습니다.

### 방법 C — 더 깊이 고치기

`index.html` 안에서 `const SEED = {` 를 찾으면 각 탭의 기본 구조와 예시 데이터가 있습니다. 카테고리 이름, 운동 종목, 상태 값 같은 것들을 여기서 바꾸면 됩니다. 탭 심볼은 `const CHAR = {` 에 인라인 SVG로 들어 있어서 원하는 그림으로 갈아끼울 수 있고, 홈 화면 앱 아이콘은 `const ICON =` 한 줄에 base64 PNG로 들어 있습니다.

## 내 데이터는 어디에 있나

**브라우저 안에만 있습니다.** 작성한 기록 데이터는 별도 서버로 전송하거나 저장하지 않아요. 그래서:

- 다른 기기에서는 안 보입니다
- 브라우저 데이터를 지우면 같이 사라집니다
- 시크릿 모드에서 쓰면 창을 닫는 순간 없어집니다

정확히 하자면, 페이지 자체는 외부에서 두 가지를 내려받습니다. 글꼴(Pretendard, jsDelivr CDN)과 — **설정 → ⚙ 고급 동기화를 직접 열었을 때만** — 구글 로그인 스크립트입니다. 동기화를 켜지 않으면 구글 쪽으로는 아무 요청도 나가지 않습니다. �
