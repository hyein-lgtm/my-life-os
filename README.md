# My Life OS

**파일 하나로 굴러가는 개인 대시보드.** 서버도, 회원가입도, 월 구독료도 없습니다. `index.html` 하나를 브라우저로 열면 그게 앱입니다.

프로젝트 · 업무 · 데일리 투두 · 독서 · 운동 · 브랜드 · 부동산 — 일곱 가지 기록을 한 화면에서 관리하고, 필요 없는 건 꺼두면 됩니다.

👉 **데모: https://hyein-lgtm.github.io/hyein-life-demo/**
(둘러보기용 예시 데이터가 채워져 있어요. 브라우저에만 저장되니 마음껏 눌러보세요.)

## 5분 만에 내 것으로 만들기

1. 이 저장소 오른쪽 위 초록색 **`Use this template`** → **`Create a new repository`**
2. 저장소 이름을 정하고 **Public**으로 만들기
3. 만들어진 저장소에서 **Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)`** → Save
4. 1~2분 뒤 `https://<내이름>.github.io/<저장소이름>/` 접속
5. 첫 화면에서 이름을 적고, 쓸 탭을 고르면 끝

자세한 그림 설명은 [DEPLOY.md](DEPLOY.md)에 있습니다.

**GitHub 없이 쓰고 싶다면** — `index.html`을 다운로드해서 더블클릭하면 그대로 동작합니다. 다만 휴대폰에서 쓰려면 어딘가에 올려두는 편이 편해요.

## 커스터마이징

### 방법 A — 화면에서 (코드 몰라도 됨)

처음 열면 안내 마법사가 세 가지를 물어봅니다.

- **뭐라고 부를까요** — 화면 곳곳에 들어가는 이름
- **어떤 걸 기록할까요** — 일곱 탭 중 쓸 것만 켜기
- **어떻게 시작할까요** — 예시 데이터로 둘러보기 / 빈 상태로 시작

나중에 바꾸려면 오른쪽 위 **⚙ 설정**에서 **🙋 내 이름**, **🎛 쓸 탭 고르기**를 누르면 됩니다. 탭을 꺼도 안에 있던 기록은 지워지지 않고 숨겨지기만 해요.

### 방법 B — 파일에서 (배포 전에 미리 정해두고 싶을 때)

`index.html` 맨 위에 설정 블록이 있습니다. 여섯 줄이 전부입니다.

```js
window.CONFIG = {
  appName:  "My Life OS",   // 앱 이름 (탭 제목 · 홈 화면 아이콘 이름)
  owner:    "",             // 나를 부르는 말. 비워두면 첫 실행 때 물어봐요
  tagline:  "",             // 부제. 비워두면 "OO's workspace"
  storeKey: "mylifeos",     // 저장소 이름표. 한 브라우저에서 2개 쓰려면 다르게
  tabs:     null,           // (예약) null = 전부
  sample:   true            // true = 예시 데이터로 시작 / false = 빈 상태로 시작
};
```

**`owner`에 이름을 적어두면 안내 마법사는 건너뜁니다.** 개발자가 이미 설정을 마쳤다고 보기 때문이에요. 마법사를 보여주고 싶으면 `owner`를 비워두세요.

`storeKey`는 브라우저 저장소의 이름표입니다. 같은 브라우저에서 "업무용"과 "개인용"을 따로 쓰고 싶다면, 파일 두 개를 서로 다른 `storeKey`로 두면 데이터가 섞이지 않습니다.

### 방법 C — 더 깊이 고치기

`index.html` 안에서 `const SEED = {` 를 찾으면 각 탭의 기본 구조와 예시 데이터가 있습니다. 카테고리 이름, 운동 종목, 상태 값 같은 것들을 여기서 바꾸면 됩니다. 캐릭터 그림은 `const CHAR = {` 에 base64로 박혀 있으니 원하는 이미지로 갈아끼울 수 있어요.

## 내 데이터는 어디에 있나

**브라우저 안에만 있습니다.** 서버로 아무것도 보내지 않아요. 그래서:

- 다른 기기에서는 안 보입니다
- 브라우저 데이터를 지우면 같이 사라집니다
- 시크릿 모드에서 쓰면 창을 닫는 순간 없어집니다

기록이 갑자기 안 보일 때를 대비한 안전장치가 세 겹 들어 있습니다. 저장 이름표만 바뀐 경우라면 앱이 알아서 예전 기록을 찾아 되살립니다. 정말 못 찾으면 **"기록을 찾지 못했어요"** 화면을 띄운 뒤 거기서 멈춥니다 — 드라이브나 백업 파일을 고르기 전까지 아무것도 저장하지 않으니, 예시 데이터가 예전 기록을 덮어쓸 일이 없어요. 그리고 기록이 절반 이하로 갑자기 줄어들면 드라이브 자동 저장을 스스로 멈춥니다.

그래도 **가끔 백업을 눌러주세요.** 툴바의 **⬇ 백업** 버튼이 JSON 파일 하나를 내려받고, 같은 자리에서 복원할 수 있습니다. 자동 동기화가 필요하면 설정에서 Google Drive를 연결하세요 (본인 Google Cloud 클라이언트 ID를 직접 넣는 방식이라, 이 저장소에는 아무 키도 들어있지 않습니다).

### 비밀번호 금고에 대해

설정 안에 숨어 있는 기능입니다. 4~6자리 PIN을 정하면 그 PIN으로 비밀번호를 **AES-GCM으로 암호화**해서 저장합니다 (PBKDF2 150,000회). PIN 없이는 저장된 데이터를 열어봐도 알아볼 수 없습니다.

- **PIN을 잊으면 복구할 방법이 없습니다.** 정말 없어요.
- 금고 내용은 일반 백업 JSON에도, Google Drive 동기화에도 **절대 포함되지 않습니다.** 별도의 암호화된 저장소에만 있습니다.
- 그래서 기기를 바꾸면 금고는 따라가지 않습니다. 중요
